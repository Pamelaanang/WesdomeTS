### 4. Built `review_timesheet` View
This is the core of UC4 — where the supervisor actually approves or rejects entries.

**How it works:**
```python
@login_required(login_url='login')
def review_timesheet(request, pk):
    if request.user.access_level != 3:
        return redirect('profile')
    
    subordinates = User.objects.filter(supervisorid=request.user)
    header = get_object_or_404(MainHeader, mainheaderid=pk, employeeid__in=subordinates)
    empdate_submitted = header.submittedat
    
    if header.overallstatus == 'Completed':
        return redirect('approval_inbox')

    entries = MainEntry.objects.filter(mainheaderid=header)

    if request.method == 'POST':
        action = request.POST.get('action')

        if action == 'approve':
            entryid = request.POST.get('entryid')
            if entryid:
                entry = get_object_or_404(MainEntry, mainentryid=entryid, mainheaderid=header)
                entry.linestatus = 'Approved'
                entry.approvedat = timezone.now()
                entry.supervisornote = request.POST.get('supervisornote') or None
                entry.approvedby = request.user
                entry.save()
                header.overallstatus = 'In Progress'
                header.save()

        elif action == 'reject':
            entryid = request.POST.get('entryid')
            if entryid:
                entry = get_object_or_404(MainEntry, mainentryid=entryid, mainheaderid=header)
                entry.linestatus = 'Rejected'
                entry.approvedat = timezone.now()
                entry.supervisornote = request.POST.get('supervisornote') or None
                entry.approvedby = request.user
                entry.save()
                header.overallstatus = 'In Progress'
                header.save()

        elif action == 'finish_review':
            header.overallstatus = 'Completed'
            header.save()
            return redirect('approval_inbox')

        return redirect('review_timesheet', pk=header.mainheaderid)

    return render(request, 'timesheets/review_timesheet.html', {
        'header': header,
        'entries': entries,
        'empdate_submitted': empdate_submitted
    })
```

**Key design decisions:**
- `employeeid__in=subordinates` — security guard ensuring supervisors can only open headers belonging to their own subordinates, not anyone else's
- Completed lock: if `overallstatus == 'Completed'`, redirect immediately — no further changes allowed
- `approve` and `reject` both flip header to `'In Progress'` on first touch — supervisor can stop and resume
- `finish_review` flips header to `'Completed'` and is the only way to lock the record
- Decisions are saved immediately per entry — supervisor can change approve→reject freely until `finish_review` is hit
- `timezone.now()` used instead of `datetime.now()` — timezone-aware, respects Django settings

## Concepts Learned Today

- **`__in` filter** — Django ORM equivalent of SQL `WHERE field IN (...)`. Used for fetching headers whose employees are in a given set.
- **`timezone.now()` vs `datetime.now()`** — always use `timezone.now()` in Django; it's timezone-aware and respects `TIME_ZONE` in settings.py
- **`@login_required` session mechanic** — the decorator reads a session cookie set by `login()`, not the URL. If no valid session exists, redirects to `login_url` with `?next=` appended so the user lands back after logging in.
- **Action pattern in POST** — one view handles multiple operations via a hidden `action` field. Cleaner than separate URLs for each operation.
- **Lock-on-completion pattern** — check `overallstatus == 'Completed'` at the top of the view and redirect immediately. Server-side guard prevents manipulation even if someone bypasses the UI.
