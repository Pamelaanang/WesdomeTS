### 1. `paidat` / `paidby` Fields — All Header Models

Added payment tracking fields to `MainHeader`, `BusinessHeader`, and `OperationsHeader`.

```python
paidat = models.DateTimeField(db_column='PaidAt', blank=True, null=True)
paidby = models.ForeignKey('users.User', models.DO_NOTHING, db_column='PaidBy',
    blank=True, null=True, related_name='paid_%(class)s')
```

`related_name='paid_%(class)s'` avoids reverse accessor clashes when multiple models reference the same User FK. If `paidat` is null → unpaid; if set → paid. No separate status field needed.

### 2. Leave Tracking Models Added — `timesheets/models.py`

Three new models to support the leave management system.

**`LeaveType`** — master list of leave categories (Vacation, Sick, Lieu Day, Floater, Unpaid):
```python
class LeaveType(models.Model):
    leavetypeid = models.AutoField(db_column='LeaveTypeID', primary_key=True)
    leavetypename = models.CharField(db_column='LeaveTypeName', max_length=255)
    isactive = models.IntegerField(db_column='IsActive', default=1)
```

**`LeaveAllocation`** — per-employee, per-year granted hours for each leave type:
```python
class LeaveAllocation(models.Model):
    allocationid = models.AutoField(db_column='AllocationID', primary_key=True)
    employeeid = models.ForeignKey('users.User', models.DO_NOTHING, db_column='EmployeeID')
    leavetypeid = models.ForeignKey(LeaveType, models.DO_NOTHING, db_column='LeaveTypeID')
    year = models.IntegerField(db_column='Year')
    allocatedhours = models.DecimalField(db_column='AllocatedHours', max_digits=5, decimal_places=2)
    isprorated = models.IntegerField(db_column='IsProrated', default=0)
```

No `usedhours` field — usage is computed dynamically from entries so it never drifts out of sync.

**`StatHoliday`** — Ontario stat holiday calendar for admin reference:
```python
class StatHoliday(models.Model):
    statid = models.AutoField(db_column='StatID', primary_key=True)
    statname = models.CharField(db_column='StatName', max_length=255)
    statdate = models.DateField(db_column='StatDate')
    isactive = models.IntegerField(db_column='IsActive', default=1)
```

### 8. `paidat` / `paidby` Moved to `OperationsEntry`

**Design decision:** For operations, the Shifter submits one header covering multiple crew members. Payroll pays individual employees — not the Shifter's sheet. Tracking payment at the header level meant "is Employee B paid for this day?" required checking the parent header, which doesn't map cleanly.

Moved to `OperationsEntry`:
```python
paidat = models.DateTimeField(db_column='PaidAt', blank=True, null=True)
paidby = models.ForeignKey('users.User', models.DO_NOTHING, db_column='PaidBy',
    blank=True, null=True, related_name='paid_%(class)s')
```

`MainHeader` and `BusinessHeader` stay at header level — one employee, one submission, one payment unit. Migration run.

## Architectural Decisions Recorded

| Decision | Resolution |
|---|---|
| Operations payment granularity | `paidat`/`paidby` on `OperationsEntry` (per employee), not `OperationsHeader` (per Shifter sheet) |
| Leave vs Work Category | Single optgroup dropdown with `wc_`/`lt_` prefixes — one field, both types, no ambiguity |
| Lieu day tracking | No separate bank table — lieu day is a `LeaveType` credited via `LeaveAllocation` like vacation |
| `usedhours` in `LeaveAllocation` | Excluded — computed from entries dynamically to avoid drift |
| Floater day proration | Full day regardless of hire date; hours based on shift length (10 or 12 hrs) |
| Stat holiday double pay | Submitted as work category "Stat Holiday Work" — payroll applies rate multiplier externally |
| Payroll nav structure | Unprocessed (new) = unpaid; Departments = history/paid |
